# IoT-Driven Vertical Farming Optimization Using Machine/Deep Learning

This project aims to optimize vertical farming through environmental monitoring and predictive modeling of plant growth stages using DL.

## 🚀 Features
- IoT-based sensor data (Temperature, Humidity, pH, CO2, Light, etc.)
- Growth stage prediction using  DL (FCNN, DL using K-fold)
- Data visualization and preprocessing
- Model evaluation and comparison

## 📁 Dataset
Contains features like:
- Nitrogen, Phosphorus, Potassium
- pH, Humidity, Temperature
- Oxygen, CO2, Light Intensity
- Growth Stage (Target)
